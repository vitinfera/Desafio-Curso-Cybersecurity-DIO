# Desafio-Curso-Cybersecurity-DIO
Este projeto tem como objetivo estudar técnicas de ataques de força bruta e password spraying em ambientes controlados, utilizando Kali Linux, Medusa, Metasploitable 2 e DVWA.

O repositório apresenta a configuração do ambiente virtual, procedimentos de análise dos protocolos FTP e SMB, estudo de autenticação web, scripts demonstrativos, wordlists de laboratório e recomendações de mitigação.

O projeto também aborda boas práticas de segurança, como políticas de senhas fortes, autenticação multifator, monitoramento de tentativas de acesso e restrição de serviços vulneráveis.

A documentação inclui roteiros para execução dos testes e registro das evidências obtidas.
